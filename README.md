# AI Tech News Automation

This is my first automation workflow built using n8n.

The workflow automatically:

* Detects new tech news using RSS feeds
* Sends the news to Gemini AI for summarization
* Delivers the summarized result to a Telegram bot

## Tools Used

* n8n
* Gemini AI
* Telegram Bot API
* RSS Feed Trigger

## Workflow Structure

RSS Feed Trigger → Gemini AI Summary → Telegram Bot
